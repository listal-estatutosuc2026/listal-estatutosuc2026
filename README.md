# Lista L — Assembleia Estatutária UC 2026

Página estática (HTML/CSS, sem JavaScript) com o programa e os candidatos da Lista L à Assembleia Estatutária da Universidade de Coimbra.

- `index.html` — conteúdo
- `style.css` — estilos
- `assets/logo-uc.jpg` — símbolo da UC

## Publicar no GitHub Pages

Settings → Pages → *Deploy from a branch* → `main` / `/ (root)`.

## Pré-visualizar localmente

```bash
python3 -m http.server 8765
```
